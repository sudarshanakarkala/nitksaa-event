## Observations for Padmanand

Seen during this run; not caused by the pull requests above.

1. **Signing out in one tab does not sign out other open tabs.** The other tab keeps its session and could still register and pay.
2. **My Events can show "No registrations yet" after an update of the sign-in state for the same user, until a reload.** It happens on `main` too: the My Events list is rebuilt empty on every auth-controller notification, and the pages fetch only when they open (details: `ISSUE-021_ROUTING_TEST_REPORT.md` §5a on PR #61). A possible fix is to rebuild it only when the session token changes, which keeps ISSUE-001's reset on a change of user.
3. **The My Events card has no QR button**, although the event page says "Your QR badge is ready in My Events". The QR works from View Details → View QR badge.
4. **Registration can stay open after the event has started** (EV Free Event as first set up: start 18:33, registration open until 22:33). In that window people can register but not unregister (ISSUE-012's rule). An event setup question.
5. **Test data on the shared backend:** a paid ₹100 TEST registration on "Test 4 Group Reg" (Padmanand's event); test registrations on "Oct15-event1" and "EV Free Event", whose dates were edited for testing.
