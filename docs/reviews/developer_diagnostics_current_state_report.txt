1. DEVELOPER DIAGNOSTICS FEATURES IMPLEMENTED
================================================================================

The Developer Diagnostics screen is a comprehensive debug-only tool for the
NITKSAA Event Flutter app. It provides:

- A categorised diagnostic centre with 6 collapsible category sections
- Quick Actions card for batch operations (Run All, Export, Clear Cache)
- Per-diagnostic detail screens with live backend API testing
- Full Validation flow: Firebase → Backend Login → /auth/me → DB tables → event_users
- API detail panel on every diagnostic (method, path, auth, purpose, sample response)
- Production warning banner (shown in debug mode only)
- Status badges per diagnostic (OK / INFO / WARNING / ERROR / N/A)
- Category-level aggregate status rollup
- Export diagnostic report to clipboard
- Clear cached backend session
- Database table viewer (tap-to-inspect table rows)
- Token preview (short truncated preview, not full token)

10. IS DEVELOPER DIAGNOSTICS DEBUG-ONLY?
================================================================================

YES. Enforced at three layers:

  Layer 1 — Route registration (app_router.dart:35-40):
    if (kDebugMode)
      GoRoute(path: AppRoutes.developer, ...)
    Route does not exist in release builds.

  Layer 2 — Route guard (route_guards.dart:19):
    if (isDeveloper && !kDebugMode) return AppRoutes.login;
    Any attempt to navigate to /developer in release is redirected to login.

  Layer 3 — Screen body guard (developer_diagnostics_screen.dart:38-40):
    if (!kDebugMode) {
      return const Scaffold(body: Center(child: Text('Not available.')));
    }
    Renders a blank "Not available" screen even if somehow reached.

13. QUICK ACTIONS IMPLEMENTED?
================================================================================

YES. The Quick Actions card (_QuickActionsCard) is rendered at the top of
the screen, above the Diagnostic Center, with three actions:

  1. Run All Diagnostics (FilledButton)
     - Opens _AuthDiagnosticDetail with mode: fullValidation
     - autoRunFullValidation: true (auto-triggers on screen open)
     - Runs: Firebase token → backend login → /auth/me → DB tables → event_users

  2. Export Diagnostic Report (OutlinedButton)
     - Builds a text report of all categories and diagnostic statuses
     - Copies to clipboard
     - Shows snackbar confirmation

  3. Clear Cached Data (OutlinedButton)
     - Calls AuthSessionStore().clear() to wipe the stored backend JWT/session
     - Shows snackbar confirmation
