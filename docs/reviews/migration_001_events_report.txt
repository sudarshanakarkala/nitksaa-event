Risks
-----
- This Product Owner schema intentionally differs from the current Alpha backend schema. Current backend/app code still expects Alpha column names such as starts_at and ends_at, so this migration should not be applied against the active Alpha backend unless the API code is migrated later.
- The existing Alpha migration remains at backend/migrations/events_db/001_create_events_alpha_schema.sql. It was not moved or modified because this task explicitly requested no old migration changes unless required.
- Applying both 001_create_events_alpha_schema.sql and 001_events.sql to the same empty database would conflict because both create an events table with different shapes.
- Later migrations must use Product Owner column names exactly, especially event_id and start_datetime.
