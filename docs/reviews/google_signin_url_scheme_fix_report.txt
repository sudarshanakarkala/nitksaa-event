Google Sign-In URL Scheme Fix Report

Root cause
- Google Sign-In on iOS/macOS requires the app bundle to declare a URL scheme matching REVERSED_CLIENT_ID from GoogleService-Info.plist.
- The runtime error reported the missing scheme:
  com.googleusercontent.apps.246773894709-70j994qk62rpn8ook12v1kfhm6f0cq8q
- apps/event_app/ios/Runner/Info.plist and apps/event_app/macos/Runner/Info.plist did not contain CFBundleURLTypes entries for this scheme.

Files inspected
- apps/event_app/ios/Runner/GoogleService-Info.plist
- apps/event_app/ios/Runner/Info.plist
- apps/event_app/macos/Runner/GoogleService-Info.plist
- apps/event_app/macos/Runner/Info.plist
- apps/event_app/lib/firebase_options.dart
- apps/event_app/lib/features/developer/presentation/developer_diagnostics_screen.dart

Files modified
- apps/event_app/ios/Runner/Info.plist
- apps/event_app/macos/Runner/Info.plist

REVERSED_CLIENT_ID used
- com.googleusercontent.apps.246773894709-70j994qk62rpn8ook12v1kfhm6f0cq8q

Source values
- iOS GoogleService-Info.plist:
  - CLIENT_ID: 246773894709-70j994qk62rpn8ook12v1kfhm6f0cq8q.apps.googleusercontent.com
  - REVERSED_CLIENT_ID: com.googleusercontent.apps.246773894709-70j994qk62rpn8ook12v1kfhm6f0cq8q
  - BUNDLE_ID: org.nitksaa.event
- macOS GoogleService-Info.plist:
  - CLIENT_ID: 246773894709-70j994qk62rpn8ook12v1kfhm6f0cq8q.apps.googleusercontent.com
  - REVERSED_CLIENT_ID: com.googleusercontent.apps.246773894709-70j994qk62rpn8ook12v1kfhm6f0cq8q
  - BUNDLE_ID: org.nitksaa.event
- firebase_options.dart uses the same iosClientId and org.nitksaa.event bundle ID for both iOS and macOS.

iOS fix
- Added CFBundleURLTypes to apps/event_app/ios/Runner/Info.plist.
- Added CFBundleURLSchemes with:
  com.googleusercontent.apps.246773894709-70j994qk62rpn8ook12v1kfhm6f0cq8q

macOS fix
- Added CFBundleURLTypes to apps/event_app/macos/Runner/Info.plist.
- Added CFBundleURLSchemes with:
  com.googleusercontent.apps.246773894709-70j994qk62rpn8ook12v1kfhm6f0cq8q
- macOS has its own apps/event_app/macos/Runner/GoogleService-Info.plist, and it contains the same CLIENT_ID, REVERSED_CLIENT_ID, and BUNDLE_ID values as iOS.
