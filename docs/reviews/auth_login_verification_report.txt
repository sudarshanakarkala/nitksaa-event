Session persistence
- Initial runtime check found a real issue: after force-stop/relaunch, the app returned to Login even though auth_session.hive existed.
- Root cause:
  AuthController._handleFirebaseAuthChanged cleared the stored backend session when FirebaseAuth emitted a null user event during startup, before/around backend JWT restoration.
- Minimal safe fix:
  Updated apps/event_app/lib/features/auth/services/auth_controller.dart so Firebase-null startup events do not clear a backend session. Explicit logout remains responsible for clearing the backend JWT/session.
- Re-test after fix:
  Force-stop and explicit relaunch triggered GET /api/v1/auth/me HTTP 200 and app opened Home.
- Result: Passed after fix.
