KNOWN LIMITATIONS (Week 1)
================================================================================

  1. No admin-role enforcement on frontend.
     Backend returns user_type. Frontend does not yet gate on it.
     Any Firebase user that passes backend /auth/me can reach the admin portal.
     Add RequireAdmin component in Week 2.

  2. Backend JWT expiry not handled gracefully.
     On 401 mid-session, apiClient hard-redirects to /login.
     Functional but not graceful — implement token refresh when backend supports it.

  3. No React error boundary.
     Unhandled render errors show a blank screen.
     Add ErrorBoundary before production.

  4. Mobile layout not implemented.
     Sidebar is fixed 240px; overflows on narrow screens.

  5. .env is present but should be added to .gitignore if not already excluded.
     The dist/ folder should also be in .gitignore.
