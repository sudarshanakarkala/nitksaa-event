Performance observations
- API calls remain explicit and developer-triggered.
- Full validation avoids requiring testers to manually perform repeated steps in sequence.
- Existing backend row limit of 50 keeps the UI bounded.
- Raw JSON is collapsed by default to reduce scrolling and rendering noise.
- Captured backend JWT is reused for diagnostics calls until refreshed.

Mobile responsiveness
- Status chips wrap naturally on narrow screens.
- Action buttons use Wrap to avoid horizontal overflow.
- Key-value rows switch to vertical layout on narrow widths.
- Database rows use compact single-line table/count layout.
- Raw JSON is collapsed by default to reduce small-screen scrolling.
