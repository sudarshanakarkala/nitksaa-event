Expected rollback result
- LoginScreen returns to placeholder handlers.
- /home route is no longer protected by backend session validity.
- Splash/AuthWrapper return to FirebaseAuth.currentUser checks.
- Home sign-out returns to Firebase-only sign-out.
- Developer Diagnostics returns to its local GoogleSignIn initialization.

Data cleanup
- The app stores backend auth data in local Hive box auth_session.
- To clear local auth state after rollback, sign out before deploying rollback or clear app data on the test device/simulator.
- No server-side data cleanup is required by this implementation.

Verification after rollback
- Run flutter analyze from apps/event_app.
- Run flutter test from apps/event_app.
- Run python -m py_compile backend/app/**/*.py from repo root if backend files are part of the rollback branch verification.
