Risks
-----
- This migration depends on Migration 001 having already created events(event_id).
- event_users.email and event_users.fullname are NOT NULL, so future auth/user creation code must provide both values.
- event_members requires a matching event_users row before membership rows can be inserted.
- No role/status CHECK constraints are included because they were not part of the provided schema.
- Current backend/app Alpha code has not been modified to use event_users or event_members.
