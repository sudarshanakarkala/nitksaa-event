event_users upsert behavior
- Inserts firebase_uid, email, fullname, user_type, ref_id, graduation_year, and last_login for first login.
- Uses firebase_uid as the conflict key.
- On existing rows, updates only email, fullname, and last_login.
- Does not overwrite existing user_type, ref_id, graduation_year, is_suspended, or created_at.
- If Firebase display name is missing, email is used as the fullname fallback.
- If the resulting event_users row has is_suspended=true, login returns HTTP 403.
