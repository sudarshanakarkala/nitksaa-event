Risks
-----
- This migration depends on Migration 001 and Migration 003 having already created events and event_users.
- event_content.added_by requires a matching event_users row before content rows can be inserted.
- content_type is intentionally limited to recording and gallery.
- This migration stores external URLs only; it does not add file upload, media hosting, metadata, created_at, updated_at, deleted_at, or storage columns.
- Current backend/app Alpha code has not been modified to use event_content.
