Category status behavior
- ERROR if any child diagnostic is ERROR.
- WARNING if any child diagnostic is WARNING and none are ERROR.
- OK if all runnable non-informational child checks are OK.
- INFO for informational-only categories or mixed informational/current state categories without failures.
- N/A when a category has no implemented diagnostics or implemented diagnostics have not run.
