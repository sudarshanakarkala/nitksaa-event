DATABASE MIGRATION
==================================================

Create:

backend/migrations/events_db/001_create_events_alpha_schema.sql

Tables:

1. events
2. sessions
3. registrations
4. attendees
5. check_ins
6. check_in_attempts

--------------------------------------------------
events
--------------------------------------------------

Fields:
- event_id BIGSERIAL PRIMARY KEY
- slug TEXT UNIQUE NOT NULL
- title TEXT NOT NULL
- description TEXT
- event_type TEXT DEFAULT 'event'
- venue_name TEXT
- venue_address TEXT
- city TEXT
- country TEXT DEFAULT 'India'
- is_virtual BOOLEAN DEFAULT FALSE
- virtual_url TEXT
- starts_at TIMESTAMPTZ NOT NULL
- ends_at TIMESTAMPTZ
- timezone TEXT DEFAULT 'Asia/Kolkata'
- capacity INTEGER
- registration_opens_at TIMESTAMPTZ
- registration_closes_at TIMESTAMPTZ
- status TEXT NOT NULL DEFAULT 'draft'
- created_by TEXT
- updated_by TEXT
- created_at TIMESTAMPTZ DEFAULT NOW()
- updated_at TIMESTAMPTZ DEFAULT NOW()

Allowed status:
draft, published, closed, cancelled

--------------------------------------------------
sessions
--------------------------------------------------

Fields:
- session_id BIGSERIAL PRIMARY KEY
- event_id BIGINT NOT NULL REFERENCES events(event_id)
- title TEXT NOT NULL
- description TEXT
- speaker_name TEXT
- location TEXT
- track_name TEXT
- starts_at TIMESTAMPTZ NOT NULL
- ends_at TIMESTAMPTZ
- capacity INTEGER
- status TEXT DEFAULT 'scheduled'
- sort_order INTEGER DEFAULT 0
- created_at TIMESTAMPTZ DEFAULT NOW()
- updated_at TIMESTAMPTZ DEFAULT NOW()

--------------------------------------------------
registrations
--------------------------------------------------

Fields:
- registration_id BIGSERIAL PRIMARY KEY
- event_id BIGINT NOT NULL REFERENCES events(event_id)
- firebase_uid TEXT
- ref_id TEXT
- email TEXT
- full_name TEXT NOT NULL
- status TEXT NOT NULL DEFAULT 'registered'
- registration_source TEXT DEFAULT 'api_alpha'
- qr_token TEXT UNIQUE
- registered_at TIMESTAMPTZ DEFAULT NOW()
- cancelled_at TIMESTAMPTZ
- cancel_reason TEXT
- metadata JSONB DEFAULT '{}'::jsonb
- created_at TIMESTAMPTZ DEFAULT NOW()
- updated_at TIMESTAMPTZ DEFAULT NOW()

Rules:
- duplicate active registration blocked
- check duplicate by event_id + email
- if ref_id exists, also check event_id + ref_id
- no cross-database FK

--------------------------------------------------
attendees
--------------------------------------------------

Fields:
- attendee_id BIGSERIAL PRIMARY KEY
- registration_id BIGINT NOT NULL REFERENCES registrations(registration_id)
- event_id BIGINT NOT NULL REFERENCES events(event_id)
- ref_id TEXT
- firebase_uid TEXT
- attendee_type TEXT DEFAULT 'alumni'
- display_name TEXT NOT NULL
- email TEXT
- phone TEXT
- badge_name TEXT
- created_at TIMESTAMPTZ DEFAULT NOW()
- updated_at TIMESTAMPTZ DEFAULT NOW()

Alpha:
- one registration = one attendee

--------------------------------------------------
check_ins
--------------------------------------------------

Fields:
- check_in_id BIGSERIAL PRIMARY KEY
- event_id BIGINT NOT NULL REFERENCES events(event_id)
- session_id BIGINT REFERENCES sessions(session_id)
- registration_id BIGINT REFERENCES registrations(registration_id)
- attendee_id BIGINT REFERENCES attendees(attendee_id)
- ref_id TEXT
- firebase_uid TEXT
- qr_token TEXT
- checked_in_at TIMESTAMPTZ DEFAULT NOW()
- checked_in_by TEXT
- method TEXT DEFAULT 'qr'
- notes TEXT
- metadata JSONB DEFAULT '{}'::jsonb

Rules:
- prevent duplicate event-level check-in for same registration

--------------------------------------------------
check_in_attempts
--------------------------------------------------

Fields:
- attempt_id BIGSERIAL PRIMARY KEY
- event_id BIGINT
- qr_token TEXT
- registration_id BIGINT
- attendee_id BIGINT
- attempt_status TEXT NOT NULL
- attempted_by TEXT
- attempted_at TIMESTAMPTZ DEFAULT NOW()
- notes TEXT
- metadata JSONB DEFAULT '{}'::jsonb

Allowed attempt_status:
success, duplicate, invalid, unauthorized

Indexes:
- events(status, starts_at)
- events(slug)
- sessions(event_id, starts_at)
- registrations(event_id, email)
- registrations(event_id, ref_id)
- registrations(qr_token)
- attendees(event_id)
- check_ins(event_id, registration_id)
- check_ins(qr_token)
- check_in_attempts(event_id, attempted_at)
- check_in_attempts(qr_token)

==================================================
BUSINESS RULES
==================================================

Event:
- created as draft
- only published events appear in public list
- registration allowed only for published events
- close event prevents further registrations

Registration:
- event must be published
- deadline must not be passed
- capacity must not be exceeded
- duplicate registration blocked
- generate qr_token automatically
- create attendee row automatically

QR:
- generate secure random token using Python secrets
- token prefix: nitksaa_evt_
- store plain token for Alpha
- add TODO for production hashing

Check-In:
- verify qr_token
- registration must belong to event
- duplicate check-in returns 409
- successful check-in updates registration status to checked_in
- every scan attempt must be logged:
  - success
  - duplicate
  - invalid
  - unauthorized
